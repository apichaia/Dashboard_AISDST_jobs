# HANDOFF SPECIFICATION FOR INTERACTIVE HTML AGENT

**Target Goal:** Generate an interactive, single-file HTML dashboard summarizing global AI, Data Science, and Statistics job market metrics based on the provided Open Data context.

**Embedded Datasets Needed (JSON Structure):**
1. `salaries`: Salary ranges ($USD) categorised by role level (Entry, Mid, Expert) and field (AI, Data Science, Statistics).
2. `skills`: Top required skills with growth percentages (e.g., Agentic AI, Python, SQL, Cloud Infrastructure).
3. `geography`: Top hiring countries and market demand percentage (e.g., Singapore, USA, UK).
4. `openDataSources`: List of primary Open Data URLs for dynamic references.

**UI/UX Requirements:**
- **Editable Content:** Use `contenteditable="true"` on dynamic text nodes (e.g., titles, metric values) allowing live editing by the user.
- **Interactivity:** Include Chart.js (or D3.js) visualizations for salary ranges and skill demand with dynamic role filtering.
- **Style:** Clean, dark-mode technical dashboard layout built with CSS Grid/Flexbox and Tailwind CSS via CDN.

**Output:** Return standalone valid HTML code containing HTML, inline CSS, and JavaScript without external build steps.
